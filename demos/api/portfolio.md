## Описание
Демо-проект серверной части для небольшой компании: клиенты, заказы со статусами, фоновые задачи (счёт, выгрузка в CRM,
уведомление клиенту). Сначала написано описание API (OpenAPI), по нему сделаны две реализации: на Go и на Python (FastAPI).
Обе работают с одной базой и проходят один набор автоматических проверок, поэтому отвечают одинаково.

Что внутри:
• вход по токену и через внешний сервис аккаунтов (Max, Яндекс ID, VK ID), у каждого пользователя свои данные;
• создание, просмотр, изменение и удаление клиентов и заказов, правила смены статусов;
• списки с фильтрами, поиском, сортировкой и постраничным выводом;
• понятные ошибки: сразу видно все неверные поля;
• защита от дублей при повторе запроса (важно для оплат и плохой связи);
• очередь фоновых задач: при сбое повтор через 1, 2, 4 секунды, после 4 неудач задача помечается и не теряется;
• Swagger с описанием всех методов: фронтенд-разработчик подключается без созвонов;
• миграции базы, более 80 автоматических проверок на обе реализации, запуск в Docker, сервер в России.

Стек: Go, Python, FastAPI, SQLite (для нагрузки: PostgreSQL), OpenAPI, Swagger, Docker, GitHub Actions.
Срок: API до 5 функций от 3 дней, проект уровня демо 5-7 дней.
