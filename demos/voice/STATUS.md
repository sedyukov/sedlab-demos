# STATUS: S4 «voice» (AI-бот для голосовых и созвонов), 2026-11-21

## Сделано
- **Веб-демо** (FastAPI + чистый JS, RU/EN, светлая и тёмная тема, адаптив). Три способа подать запись: заготовленный пример, свой файл (аудио или видео) или микрофон. Дальше конвейер: расшифровка → саммари → задачи (кто / что / срок) → ответ голосом. Есть переключатель LLM (OpenAI / Anthropic / GigaChat / YandexGPT), правка текста с пересчётом и копирование задач в Markdown.
- **Демо-режим без ключей**: три примера с готовыми результатами, сгенерированы `tools/make_samples.py` (голоса macOS `say`, имена вымышленные): EN-стендап mp3, RU-созвон mp4 (видео), RU-голосовое ogg/opus. Свои файлы в этом режиме идут через mock модуля ai. Для записи с микрофона в Chrome и Safari работает распознавание речи браузера; голосовой ответ озвучивается голосом браузера (speechSynthesis).
- **Живой режим** включается ключами `AI_*`, весь доступ к моделям идёт через модуль ai. Лимиты: N запусков в час на IP (`VOICE_IP_PER_HOUR=6`), общий дневной лимит (`VOICE_DAILY_LIVE=120`), длина аудио до `VOICE_MAX_AUDIO_SEC=180` (браузер перекодирует файл в WAV 16 кГц, сервер проверяет длину по заголовку), размер до `VOICE_MAX_UPLOAD_MB=10`. Слишком длинное аудио и запросы сверх лимитов отклоняются до платного вызова. GigaChat работает через корневой сертификат Минцифры, он лежит в образе (`certs/`, `AI_GIGACHAT_CA_FILE`).
- **ПД (R9/R2 legal-ru)**: демо ничего не хранит. Ключи лимитера (IP, chat_id) лежат только в памяти, в виде хэша с солью процесса, и сбрасываются раз в сутки. LLM по умолчанию — российские (GigaChat, затем YandexGPT), и в переключателе они стоят первыми.
- **Telegram-бот** (по желанию, `VOICE_TELEGRAM_TOKEN`): long polling в том же процессе. Принимает голосовое, аудио, кружок или видео; в ответ присылает текст (расшифровка, саммари, задачи) и голосовое (TTS в opus). Лимиты общие с веб-демо. Вся работа с Telegram идёт через telegram-core (`get_updates`, `download_file`, `send_voice`).
- **Тесты**: 33 штуки, `pytest -q`. Покрывают демо-режим, живой режим с фейковыми провайдерами, лимиты по IP и дневной, парсер WAV и цикл бота на MockAPI из telegram-core.
- **CI**: `.github/workflows/build-voice.yml` — тесты, затем сборка `ghcr.io/sedyukov/voice:sha-xxxxxxx`. Пакет PRIVATE, без кэшей и артефактов, правила SECURITY.md соблюдены.
- **Образ**: python:3.12-slim, 140 МБ, около 85 МБ RAM в работе, `mem_limit 160m`. Compose: `~/freelance/infra/compose/voice` (по шаблону).
- **Медиа**: `media/` — 5 скриншотов, `demo.mp4` (39 с) и `demo.gif`. README (RU и EN, цены и сроки утверждены владельцем), `portfolio.md` (RU и EN).

## Осталось / зависит от владельца
- Передеплой: `~/freelance/infra/deploy.sh voice --tag sha-<новый>` (теги — из CI build-voice).
- Живой режим (решение 2026-11-21, правило юрисдикции): для RU — только российский стек на российском VPS. LLM: GigaChat или YandexGPT (в модуле готовы). STT и TTS: Yandex SpeechKit (модуль ai 6e75a73). Демо подключено: при `AI_YANDEX_API_KEY` (или IAM) SpeechKit выбирается раньше OpenAI. Браузер шлёт WAV 16 кГц, для примеров есть копии `samples/*/stt.ogg`. Бот при SpeechKit просит голосовое или mp3/ogg вместо кружков и m4a; если они понадобятся, нужен ffmpeg в образе на RU-хосте. На freelance-1 (DO) остаётся только демо на моках. OpenAI и Anthropic на нашем демо не включаем: это опция для иностранных заказчиков на их ключах.
  - Через ru-relay (telegram-core/ai, коммит 634ed4d в модулях) после подъёма RU-VPS: `AI_GIGACHAT_BASE_URL=https://<relay>/…/api/v1`, `AI_GIGACHAT_AUTH_URL=<полный URL OAuth через relay>`, `AI_YANDEX_BASE_URL=https://<relay>/<префикс>` (только префикс), `AI_YANDEX_STT_BASE_URL=$R/yandex/stt`, `AI_YANDEX_TTS_BASE_URL=$R/yandex/tts`, `AI_YANDEX_OPERATION_BASE_URL=$R/yandex/operation`. Определение живых провайдеров в `providers.py` от relay не зависит: смотрит только на ключи. Пока не включать.
- Telegram-бот: токен BotFather → `VOICE_TELEGRAM_TOKEN`.
- Когда будет живой режим на RU VPS: пересчитать результаты примеров настоящими моделями (сейчас они составлены вручную по сценарию) и снять видео в живом режиме.
