What’s inside

  • Speech-to-text for voice notes, calls and video files (Whisper / gpt-4o-transcribe), timestamps per segment.
  • Summary and action items with owner and due date as JSON — ready to push to a CRM, Notion, Jira or a Google Sheet.
  • One LLM interface: OpenAI, Anthropic, GigaChat, YandexGPT (or a local model) — switch by config, no code changes.
  • Voice reply (TTS) — in a Telegram bot it comes back as a voice message.
  • Cost control: rate limit per user, daily budget, maximum audio length.
